# 三軸試験機 (最終用途)

このプロジェクトの最終用途。現行 MVP ([[tutorials/wifi-api-server|Wi-Fi API サーバ]]) は
試作であり、最終的には三軸試験機の載荷フレーム制御 + 応力計測を行う。

## 計測要件

- ひずみゲージによる応力計測
- **80 Hz サンプリング** (載荷速度急変時の応力変化を捉えるため)
- 制御プログラムは試験ごとに変わる → **PC 制御がメイン**
  (詳細は [[tutorials/wifi-api-design-notes#通信方式の選択]])

## ノイズ分析 (結論)

80 Hz サンプリングでも WiFi / Bluetooth の 2.4 GHz 帯が測定に影響することは**実質ない**。

- 測定帯域 (~40 Hz, ナイキスト) と 2.4 GHz は約 7 桁離れている
- ひずみゲージは DC 励起の抵抗ブリッジで、増幅器で帯域整形される

実際に気にするべきノイズ源:

- **エイリアシング** (最重要): モーター駆動のスイッチングノイズ等の高周波成分が、
  80 Hz サンプリングで帯域内の偽信号に折り返す
  → 対策: カットオフ ~40 Hz のローパスフィルタ (増幅器内蔵のことが多い)
- **GND ループ**・**伝導ノイズ**: 電源ラインや共有 GND 経由で入り込む
  → 対策: 配線の分離・ツイストペア / シールド線
- **ステッパーの機械的ステップ振動** (無線方式と独立のメカニカル問題)

→ 通信方式の選択と測定品質は独立。データ量も 80 Hz × 2 B = 160 B/s で
通信帯域は USB / WiFi とも全く問題にならない。

## サンプリング実装方針

- サンプリングは **MCU 内のタイマ駆動**で行い、タイムスタンプ付きでバッファしてから送信
- 通信の遅延ジッタをサンプリング間隔に影響させない (WiFi のジッタも無視できる)

## 用語 (inline 定義)

- **ひずみゲージ**: 伸び縮みで電気抵抗が変わる薄いセンサー
- **抵抗ブリッジ (ホイートストンブリッジ)**: 抵抗 4 個の菱形回路。1 個の抵抗変化を電圧のずれに変換
- **DC 励起**: ブリッジに一定電圧をかける方式
- **カップリング**: ある回路のエネルギーが別の回路に「くっついて」入り込むこと
- **インピーダンス**: 電流の流れにくさ。高インピーダンス回路はノイズの影響を受けやすい
- **エイリアシング**: 高周波ノイズが低いサンプリング周波数の偽信号に折り返して見える現象
- **ローパスフィルタ (LPF)**: 指定周波数以下を通し、以上を遮断するフィルタ
- **伝導ノイズ**: 電波ではなく電源・GND 配線を伝って入るノイズ
- **GND ループ**: 複数経路で GND がつながることでできる循環電流。測定ノイズの原因
- **ツイストペア**: 2 本を撚った配線。ノイズを 2 本均等に乗せて差動で打ち消す
- **シールド線**: 金属網で包んだ配線。外乱を網で受けて GND に逃がす
