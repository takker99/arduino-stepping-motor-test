# MB102 Breadboard Power Supply Module

ブレッドボード用電源モジュール。3.3 V と 5 V の 2 レールを出力できる。
本プロジェクトでは **[[28byj-48]] の 5V 給電** に使用する (Arduino は別系統)。

## 物理仕様

| 項目 | 値 |
| --- | --- |
| 入力電圧 | **6.5 – 12 V DC** (5.5 mm × 2.1 mm barrel) |
| 出力電圧 | **3.3 V** または **5 V** (各レール独立にジャンパ選択可) |
| 最大出力電流 | < 700 mA (各レール合計、AZ-Delivery datasheet 表記) |
| 寸法 | 約 5.3 cm × 3.5 cm |
| 互換性 | MB102 規格ブレッドボードに直挿し |

## 回路構成

```
                  ┌──────────────────┐
   DC IN (barrel) │      SW1         │  ON/OFF スイッチ
        ────►─────┤  1N4007 (逆接保護)├──►────┐
                  └──────────────────┘        │
                                              ▼
                                       ┌─────────────┐
                                       │ AM1117-5    │──► 5V rail
                                       │ (AMS1117)   │     (max 700 mA)
                                       └─────────────┘
                                              │
                                       ┌─────────────┐
                                       │ AM1117-3.3  │──► 3.3V rail
                                       │ (AMS1117)   │     (max 700 mA)
                                       └─────────────┘
                                              │
                                              ▼
                          ┌────────────────────────────────┐
                          │ J1 / J2 ジャンパで各レールに    │
                          │ OFF / 3.3V / 5V を選択         │
                          └────────────────────────────────┘
                                              │
                                              ▼
                          J4, J5, J6, J7 → ブレッドボード電源レール
                          (両側独立、上段 + 下段で別レール)
```

- **逆接保護**: DC IN 側に **1N4007** ダイオード (電圧降下 ≈ 0.7 V)
- **スイッチ**: SW1 で ON/OFF
- **LED インジケータ**: VD1 (470 Ω 抵抗経由)
- **USB-A コネクタ**: **出力専用** (5V を外部デバイスに給電する。MB102 自身には給電しない)
- **コンデンサ**: 入力 10 nF + 100 µF/16 V バルク、LDO 出力 10 nF

> 📌 注意: データシートによって「最大出力 300 mA」(AZ-Delivery) と
> 「< 700 mA」(Handson Technology mb102-ps) で記載が異なる。
> [[ams1117|AMS1117]] 単体の絶対最大定格は **1 A** だが、
> 実装上の放熱・ドロップアウトを考慮し、本プロジェクトでは
> **1 レールあたり 500 mA 未満に抑える** ことを安全マージンとする。

## ジャンパ設定

MB102 の **両側** (上段レール / 下段レール) はそれぞれ独立に、
ジャンパで `OFF` / `3.3V` / `5V` を選択できる (4 ピン × 2 系統)。

本プロジェクトでの推奨設定 (モーター 5V のみ使用時):

| レール | ジャンパ | 用途 |
| --- | --- | --- |
| 上段 (J1) | **5V** | [[28byj-48]] 駆動用 (赤レール = +5V, 青レール = GND) |
| 下段 (J2) | **OFF** | 未使用 (3.3V/5V のどちらにも切替可) |

> ⚠️ ジャンパを **OFF にしないと** LED インジケータもブレッドボード電源レールも
> 通電されない (データシート注記)。

## 本プロジェクトでの使い方

### 電源トポロジ (2026-08-10 決定)

```
   9V 1.3A AC アダプタ
        │
        ▼
   MB102 DC IN (barrel)
        │
        ├─► AMS1117-5.0 ──► 5V レール ──► 28BYJ-48 (Red/Blue コイル)
        │
        └─► AMS1117-3.3 ──► 3.3V レール (未使用 / 予備)

   Arduino UNO R4 WiFi は **USB-C 経由で別系統から給電**
   (開発時 = PC USB / 本番運用時 = 別 USB 充電器)
```

**Arduino は MB102 から給電しない**。理由:
- AMS1117 の 700 mA 枠を Arduino (≈ 250 mA peak with Wi-Fi) と
  28BYJ-48 (≈ 400 mA peak) で分け合うとカツカツ
- Wi-Fi ピーク突入 + モーター 2 相同時励磁 の最悪条件で AMS1117 が
  熱的に厳しくなる
- 開発中 (USB 接続時) は Arduino 側の 5V ピンからモーターに逆流するのも避けたい

詳細は [[tutorials/mb102-power-wiring]] を参照。

### ブレッドボード配線例

```
   MB102           Breadboard
  ┌──────┐         ┌─────────────────────────────────┐
  │ 5V   ├────────►│  + (赤レール) ── 28BYJ-48 Red   │
  │ GND  ├────────►│  - (青レール) ── 28BYJ-48 Blue  │
  │      │         │                  ULN2003 GND    │
  │ OFF  │         │                  ULN2003 COM ←  │
  │      │         │                  (← 5V レールから)│
  └──────┘         └─────────────────────────────────┘

   GND は Arduino の GND とも共通化する
   (USB 給電の Arduino と MB102 の GND をブレッドボードの青レールで接続)
```
