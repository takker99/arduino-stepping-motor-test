# 28BYJ-48

小型 5 V ユニポーラ・ステッピングモーター。**SparkFun / Kiatronics 製**の
「ULN2003 driver board」モジュールで市販されていることが多い。
本プロジェクトの駆動対象。

## 主要スペック

| 項目 | 値 |
| --- | --- |
| 定格電圧 | 5 V DC |
| 相数 | 4 |
| 減速比 | 1/64 |
| ステップ角 (内部) | **5.625 °** |
| ステップ角 (出力軸、減速後) | 5.625 / 64 ≈ **0.08789 °** |
| 1 回転のステップ数 (出力軸基準) | **360 / 0.08789 ≈ 4096** |
| DC 抵抗 (1 相) | 50 Ω ±7 % (25 °C) |
| 励磁周波数 | 100 Hz |
| 無励磁引込周波数 | > 600 Hz |
| 無励磁脱出周波数 | > 1000 Hz |
| 引込トルク | > 34.3 mN·m (120 Hz) |
| 自己保持トルク | > 34.3 mN·m |
| 摩擦トルク | 600–1200 gf·cm |
| 絶縁抵抗 | > 10 MΩ (500 V) |
| 動作温度 (max) | 温度上昇 < 40 K (120 Hz) |
| 騒音 | < 35 dB (120 Hz, 無負荷, 10 cm) |
| コネクタ | JST XHP-5 (SXH-001T-P0.6) |

> **注意**: データシートの "Stride Angle 5.625°/64" は
> 内部ロータのステップ角 5.625° × 1/64 減速比を意味する。
> 出力軸基準では 1 ステップ ≈ 0.088°、1 回転 ≈ 4096 ステップ。

## 電気的計算

- 5 V / 50 Ω → **1 相あたり約 100 mA** (公称)
- **実測は約 23 Ω / 相半コイル** (2026-08-13 実機確認, 赤↔青・赤↔黄とも 23Ω)。
  データシートの 50Ω は公称/フルコイル相当で、実機は 22–24Ω が典型
  (NYU ITP PhysComp の測定ガイドでも同様の値)。12V 版は 200Ω。
  → 実機の消費電流は (5 V − 1 V) / 23 Ω ≈ **174 mA / 相**、2 相励磁で ≈ 350 mA
  (定格 100 mA を超えるが実機では普通。動作時の発熱は想定内、ULN2003 は余裕)
- 2 相励磁時: 200 mA ピーク (公称ベース)
- GPIO で直接駆動不可 ([[arduino-uno-r4-minima]] は 8 mA / pin)。
  → 必ず [[uln2003]] を介す。

## 配線 (5 線 + ULN2003 driver board)

![Dimensional drawing](raw/28byj-48/step-motor-5v-28byj48-datasheet.pdf)

データシート末尾の pin 図より、5 本のワイヤ色は次のとおり:

| Wire color | Pin (JST XHP-5) | 機能 |
| --- | --- | --- |
| Blue | 1 | Phase A (coil 1 端) |
| Pink | 2 | Phase B (coil 2 端) |
| Yellow | 3 | Phase C (coil 2 端) |
| Orange | 4 | Phase D (coil 1 端) |
| Red | 5 | **COM (センタータップ = +5 V)** |

> **注意**: Phase A と B は **別々のコイル**。同様に C と D は別のコイル。
> 「coil 1 端」「coil 2 端」とあるのはメーカー図面上のラベルで、
> コイルペア = (A, B) と (C, D) と考えてよい。
> どの色がどの coil の端かはメーカー定義に従う。

データシートの内部接続図から:

```
   (Red 5 ── COM ── Coil A ── 1 Blue)
                       └── Coil B ── 2 Pink
                       └── Coil C ── 3 Yellow
                       └── Coil D ── 4 Orange
```

実機ドライバーボード ([ULN2003 driver board]) 経由の場合:

| ULN2003 driver board 端子 | 接続先 | 備考 |
| --- | --- | --- |
| IN1 | Arduino D7 | coil A (Blue) を駆動 |
| IN2 | Arduino D6 | coil B (Pink) を駆動 |
| IN3 | Arduino D5 | coil C (Yellow) を駆動 |
| IN4 | Arduino D4 | coil D (Orange) を駆動 |
| + (5V) | Arduino 5V **または** 外部 5V | Red (COM) へ +5V を供給 |
| – (GND) | Arduino GND | ULN2003 側の GND |

> **実機は DIP 化基板 (2026-08-13 確認)**: 標準ドライバーボードの端子台は無く、
> ULN2003AN を直接配線している。対応は 1B=IN1(D7) / 2B=IN2(D6) / 3B=IN3(D5) /
> 4B=IN4(D4) / E(8)=GND / COM(9)=+5V / 1C–4C(16–13)=Blue/Pink/Yellow/Orange。
> 詳細は [[uln2003#DIP 化基板 (本プロジェクトの実機構成, 2026-08-13 確認)]]。

### GND の共有

**Arduino GND, [[uln2003]] GND, モータ用 5V 電源の GND をすべて共通**にする。
これがないと、Arduino の GPIO HIGH を ULN2003 が正しく検出できない。

### 電源の選択

- **USB 給電で間に合うか?** 1 相 100 mA × 2 相 = 200 mA。
  UNO R4 Minima の 5V ピンは USB 給電時 2 A まで理論上は提供可能だが、
  PC の USB ポートの制限 (通常 500 mA) に注意。
- **推奨**: モータ用に **別電源の 5V を用意**し、GND のみ共通にする。
  電池ボックス (単3 × 4 本 = 6V を三端子レギュレータで 5V) や、
  USB 充電器 + 昇降圧コンバータ等。

## 1 ステップの所要時間

減速比 1/64、内部ステップ角 5.625°。[[stepper-library]] を使う場合:

```cpp
// 出力軸 1 回転 = 4096 ステップ (32 ステップ/cycle × 64 × 2 相当)
Stepper myStepper(4096, 7, 6, 5, 4);  // D7, D6, D5, D4 (実機配線, 2026-08-12 確定)
```

ただし、内部 half-step シーケンスを使うか full-step シーケンスを使うかで
1 回転あたりのステップ数が変わる。[[stepper-library]] のデフォルトは
**2 相励磁 (full-step)** で、**内部ステップ 4 step × ギア比 64 = 256** が
1 回転。 ただし、実機では負荷時に "missed step" を考慮して 4096 にすると
確実 (over-spec)。
