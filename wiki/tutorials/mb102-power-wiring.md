# MB102 電源配線

9V 1.3A AC アダプタ → [[mb102|MB102]] → ブレッドボード経由で [[28byj-48]]
(と [[uln2003]]) に給電する配線チュートリアル。
[[arduino-uno-r4-wifi|UNO R4 WiFi]] は **USB 経由で別系統から給電**する。

## 部品リスト

| 部品 | 個数 | 備考 |
| --- | --- | --- |
| 9V 1.3A AC アダプタ (5.5 × 2.1 mm barrel) | 1 | センタープラス |
| MB102 ブレッドボード電源モジュール | 1 | ジャンパ 4 ピン × 2 系統が付属しているか確認 |
| ブレッドボード | 1 | MB102 規格 (電源レールの溝が両端) |
| USB-C ケーブル | 1 | Arduino 給電 + 書き込み兼用 |
| ジャンパワイヤ (オス–オス) | 適数 | 5V/GND 分配用 |

## ジャンパ設定

MB102 の両側レール (上段・下段) は独立にジャンパ設定。
本プロジェクトでは **上段のみ使用**:

| ジャンパ | 設定 | 用途 |
| --- | --- | --- |
| J1 (上段) | **5V** | 28BYJ-48 / ULN2003 への 5V 給電 |
| J2 (下段) | **OFF** | 未使用 |

> ⚠️ 両ジャンパが `OFF` だと LED も通電されない (データシート注記)。

## 配線手順

1. **MB102 をブレッドボードに挿す**
   - モジュールの (−) 側をブレッドボードの青レール側に合わせる
   - ジャンパを上段 5V、下段 OFF に設定
2. **9V アダプタを MB102 の DC IN に接続**
   - センタープラス、5.5 × 2.1 mm barrel
   - 緑の LED が点灯すれば通電 OK
3. **赤レール (上段 +) に 28BYJ-48 の Red (5V) と ULN2003 の COM を接続**
   - 28BYJ-48 の赤線は ULN2003 の COM 端子ではなく直接 5V に繋ぐ派もあるが、
     本プロジェクトでは ULN2003 COM 経由 (フリーホイールダイオード保護が効く)
4. **青レール (上段 −) に 28BYJ-48 の Blue とは別系統の GND を共通化**
   - 28BYJ-48 Blue コイル線 → ブレッドボードの GND
   - ULN2003 GND → ブレッドボードの GND
   - Arduino GND → ブレッドボードの GND (**GND 共通化が必須**)
5. **ULN2003 IN1〜IN4 を Arduino D8〜D11 に接続**
6. **Arduino を USB-C で PC に接続**
   - 開発中は PC USB から給電
   - 本番運用時は別 USB 充電器から給電

## GND 共通化 (必須)

```
   USB Arduino GND ────►  Breadboard GND (青レール)  ◄──── ULN2003 GND
                                                    ◄──── 28BYJ-48 Blue
```

Arduino (USB 給電) と MB102 (9V → 5V) は **電気的に絶縁された別電源**。
信号線 (D8-D11) で繋ぐためには GND を共通化する必要がある。

## 電源トポロジの選択理由 (再掲)

[[arduino-uno-r4-wifi#電源トポロジ|overview の電源トポロジ節]] で議論した通り、
**Arduino も MB102 から給電する案** は検討した。
AMS1117 の 700 mA 枠 ([mb102]) を Arduino (≈ 250 mA peak with Wi-Fi) と
28BYJ-48 (≈ 400 mA peak) で分け合うと余裕がない。
最悪条件 (Wi-Fi ピーク + 2 相同時励磁) で [[ams1117|AMS1117]] が熱的に厳しくなる。
→ **Arduino は USB 給電で別系統** に決定。

## トラブルシューティング

### モーターが回らない

- MB102 の LED は点灯しているか → DC IN 接続確認
- ジャンパが `OFF` になっていないか
- 5V レールにテスタを当てて 5V 出ているか
- GND 共通化されているか (USB Arduino と MB102 で GND が浮いている)

### モーターが回ったり回らなかったり / 脱調

- 電圧ドロップ: 9V アダプタが 1.3 A 容量であることを確認 (弱ると MB102 入力が落ちドロップアウト)
- 配線抵抗: ブレッドボードの接触不良 (ジャンプワイヤを別の列に挿し直す)
- 詳細は [[tutorials/unipolar-stepper-motor]] 参照

### Arduino のシリアルモニタに何も出ない

- USB 給電の確認 (PC の USB ハブ経由は給電不足になる場合あり)
- ドライバ: UNO R4 WiFi はデフォルトで ESP32-S3 経由で USB が見える
  (特別なドライバ不要のはず。`dmesg` 等で `ttyACM0` 出現を確認)
